`sRGB2014.icc.base64` is a base64 transport of the unmodified sRGB2014.icc
profile published by the International Color Consortium
(https://registry.color.org/rgb-registry/profiles/sRGB2014.icc, SHA-256
`384b832de3412066743b52a75ee906b6fb9fb8d9e09e936fc2c43223815c6e0a`). The ICC's
license permits copying, distribution and use without restriction; altered
versions must not be represented as the original. The package embeds it as the
colour-conversion destination profile of the image operations; tests use it as well.
